# Brand assets

The wcvm logo: a hexagon (the outline of a cube seen from above - the container) with a terminal prompt
inside. The wordmark is drawn from strokes, so none of the SVGs needs a font.

| File | Use |
|---|---|
| `logo.svg` | Mark + wordmark for light backgrounds. |
| `logo-dark.svg` | Mark + wordmark for dark backgrounds. |
| `logo-mark.svg` | The mark alone (favicon, avatar). Studio's favicon is a copy of it. |
| `logo-mark-512.png` | The mark as a 512 px PNG with a transparent background. |
| `social-preview.png` | 1280x640 image for the GitHub social preview (Settings, Social preview). |

Colours: `#8F7CFF` to `#5236E0` (gradient), text `#1C1B2E` on light and `#F3F2FF` on dark.
